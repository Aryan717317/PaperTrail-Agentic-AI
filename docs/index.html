Developer Setup

Start Investigating in Minutes

Complete local setup guide with zero complex external dependencies.

python >= 3.11 
# 1. Clone repository
git clone https://github.com/Aryan717317/PaperTrail-Agentic-AI.git
cd PaperTrail-Agentic-AI

# 2. Setup virtual environment & dependencies
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. Configure OpenRouter API key in .env
cp .env.example .env

# 4. Verify test suite (20 unit & integration tests)
pytest -v

# 5. Launch the Streamlit workspace (Dual-Mode out-of-the-box!)
streamlit run ui.py
