Advanced Research Intelligence

Built specifically for academic researchers analyzing dozens of conflicting studies.

📑

Structured Claim Extraction

Extracts hypotheses, findings, methodologies, metrics, and limitations into typed schemas linked to verbatim quotes and page numbers.

⚖️

Cross-Paper Comparison

Generates side-by-side matrices contrasting datasets, benchmarks, and architectures—explaining differences in experimental conditions rather than naively ranking numbers.

⚡

Contradiction Detection

Categorizes cross-paper discrepancies into direct contradictions, partial disagreements, or context-dependent divergence based on experimental baselines.

🔍

Evidence Quality Check

Evaluates whether a claim is directly supported, indirectly inferred, extrapolated, or unsupported by your literature collection.

🔒

Offline Embedding Privacy

Embeddings run 100% locally on CPU via Sentence Transformers (all-MiniLM-L6-v2). No proprietary embeddings API charge or data leakage.

🎯

Page-Level Traceability

Every generated answer is anchored by [S1], [S2] source labels, verified by citation integrity algorithms.

System Architecture

Decoupled 7-layer design allowing independent frontend, backend, vectorstore, and LLM upgrades.

LAYER 1

Multi-Tab Streamlit Dashboard

Document library management, paper selector checkboxes, and tabs for Q&A, Claims, Comparisons, Contradictions, and Evidence Checks.

Frontend (UI)
LAYER 2

FastAPI Modular REST API

Streams uploads with 25MB cap, exposes health probes, paper lifecycle, and asynchronous research endpoints.

Backend
LAYER 3

PyMuPDF Extraction & Boundary-Aware Chunker

Page-by-page extraction, header/footer cleaning heuristics, and paragraph-respecting recursive chunking with SHA-256 chunk IDs.

Ingestion
LAYER 4

Sentence Transformers (all-MiniLM-L6-v2)

Generates normalized 384-dimensional dense vectors locally on CPU without network calls or API cost.

Embeddings
LAYER 5

ChromaDB Vector Store

Persistent on-disk storage with chunk-level deduplication, multi-paper scoped filtering, and single-paper deletion.

Vector DB
LAYER 6

LangGraph Stateful Orchestration

Executes conditional sufficiency routing: abstains safely when evidence is lacking, or drafts answers citing source labels.

AI Workflow
LAYER 7

OpenRouter Unified LLM Gateway

Configurable model routing (default: openrouter/free) with automatic retries and custom headers.

Get Started in 3 Minutes

Run PaperTrail locally on Windows, macOS, or Linux.

# 1. Clone repository git clone https://github.com/Aryan717317/PaperTrail-Agentic-AI.git cd PaperTrail-Agentic-AI # 2. Create virtual environment & install dependencies py -3.12 -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\Activate.ps1 pip install -r requirements.txt # 3. Add your free OpenRouter API key in .env cp .env.example .env # 4. Run automated test suite pytest -v # 5. Launch FastAPI backend uvicorn app.main:app --reload --port 8000 # 6. Launch Streamlit UI (in a separate terminal) streamlit run ui.py
